# interview-prep-skill

校招面试准备 Claude skill，面向 AI 产品运营 / 增长 / 营销方向。

## 能做什么

- 丢一个 JD 进去，出针对性的准备材料：情景题预测、八大问该用哪段经历讲、短板怎么应对、反问
- 用宝洁八大问一问一问打磨自己的实习经历
- 模拟面试，一问一答再点评追问
- 面完整理被问到的题，补进题库

## 结构

```
SKILL.md                         主文件：工作流程、讲经历策略、表达规则
references/eight-questions.md    宝洁八大问 + 考察点 + 追问方向
references/interviewer-focus.md  校招面试官看重什么（面经整理）
```

## 使用

下载本仓库为 zip，在 Claude 的技能设置里上传即可。
